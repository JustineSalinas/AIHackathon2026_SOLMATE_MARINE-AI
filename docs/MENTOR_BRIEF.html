Marine-AI — Mentor & Judge Brief

Team SOLMATE · Blue Economy track · retrofit AI advisory system for Philippine passenger bancas
334 tests passing ruff + tsc clean advisory layer: claude not yet deployed every figure below verified against running code
The one sentence. Three AI modules and an auditable emissions layer on one screen, where the models predict and detect but never decide — the optimiser picks the RPM, the planner picks the track, a deterministic rule table trips the alarms, and a language model only re-words the result. That boundary is enforced by a test, not described in a doc.

02Where the AI actually works

Four places real learning happens — and the places it deliberately does not.

learned

Fuel wear model

XGBoost → ONNX. Learns the fuel penalty of a worn engine across 1,326 degradation states.

learned

Sea-state forecaster

9 targets raced against a climatological table on held-out weather. The table won 5, gradient boosting won 4. Both shipped.

learned

Anomaly detector

Learns this engine's healthy correlations, so a correlated rise reads differently from a lone drift.

phrasing only

Claude / Gemini

Re-words one sentence. Learns nothing, decides nothing. Rewrite discarded if it alters a number or issues an order.

Where a model is forbidden

  • The throttle optimiser — services/speed/optimizer.py imports exactly two modules: fuel and resistance. No model, no LLM.
  • The safety engine — test_safety_never_imports_a_model reads the module's own source and fails if anyone adds one. The boundary is a test, not a promise.
  • The pathfinder (BAIRRT / A* / D* Lite) is classical search, not machine learning. Defensible as AI in the planning sense — but if asked "what did you train?", the answer is the three above.

The demo beat worth asking us to run

Hold the coolant gauge at a constant 87.4 °C and change only how it got there:
· reached by a load-coupled rise (coolant, exhaust, NOx, vibration all moving together) → 0.30, stays nominal
· reached by a coolant drift alone → 0.62, flags, names the coolant stream
· pushed to 98 °C alone → 0.9998

Same number on the gauge, opposite verdict. A threshold detector cannot tell those two apart — that correlation is precisely what the PCA half learned.

Bias & representativeness — stated unprompted

This project processes no personal data. Inputs are engine telemetry, vessel geometry and metocean forecasts; passenger count enters only as mass in kilograms. There is no demographic attribute to balance across — so rather than claim exemption, we disclose the axes that do apply to a marine dataset:
bias 1 — prime mover

Trained on the wrong engine

A 27 MW gas turbine advising a ~60 kW diesel. Mitigation: only the dimensionless wear penalty transfers. Borrowing the part-load curve would have overstated savings by ~5×, in our own favour — measured, then rejected.

bias 2 — geography

Has seen one strait

A 9-point grid over ~20 km of the Iloilo Strait. It will not generalise, and the failure is silent because a climatological lookup always returns a number. forecast_source is reported on every response.

bias 3 — baseline

Synthetic, not this vessel

The detector measures deviation from a modelled healthy engine, not the specific one it watches. False-positive rates on a real vessel are unknown and unclaimed.

bias 4 — hardware

Nothing physical in the loop

Every frame is simulated and labelled source="simulator" in the contract, which has no default that could claim otherwise.

Choices made on licence grounds

  • Google / Bing / Esri tiles — rejected twice. An earlier build rendered Google satellite tiles credited on screen, which their terms do not permit in that form. Replaced with Sentinel-2 (CC BY 4.0).
  • FEMTO/PRONOSTIA — named in our own profile, then not used. It is 25.6 kHz bench-rig vibration; the retrofit IMU logs at ~1 Hz. Using it would imply a diagnostic capability the sensor cannot deliver.
  • AI development tools disclosed. Claude Code assisted development; contributed commits carry a Co-Authored-By trailer, so the extent is auditable from git log rather than asserted.

Degradation is a designed state, not a failure. No API key, an expired key, a rate limit, a timeout, a rejected rewrite — all land on the same path: the deterministic sentence, labelled template. The demo cannot break because of the LLM.

07Likely questions, answered straight

Does the AI decide anything?

No. Deterministic code picks the RPM and the track; a rule table trips the alarms. The optimiser imports only fuel and resistance. A test fails if a model is ever imported into the safety path. The AI proposes, the physics validates, the captain commands.

Why not train one end-to-end model?

Because no public dataset supports it. Verified by inspection before any model was written: the anchor dataset is a factorial grid in which wind, current, wave height and passenger load do not vary at all — not as weak signals, as constants. A model trained on it and presented as having learned weather would ignore the very inputs the product acts on, while reporting confidence about them.

How is the display tested?

It isn't. That is the honest answer. 334 tests cover the decision path; the front-ends have no test runner, and every display bug we found needed a browser. Adding one is the first post-hackathon task.

A gas turbine for a diesel — isn't that invalid?

It is a documented proxy, and we measured the limit rather than assuming it. Only the dimensionless wear penalty transfers. The part-load curve explicitly does not: the turbine burns ~7× best-point SFC at 10% load where a diesel burns ~1.5×, so borrowing it would have overstated our savings by roughly 5× — in our own favour. Absolute fuel level comes from a published diesel BSFC curve instead.

Did you train the Temporal Fusion Transformer your profile promised?

No, and the honest answer is better than a yes. A TFT forecasts from recent observed history, and this endpoint has none to give it. What trains instead is a position-and-time regression — and even that was not shipped as one architecture: nine targets were raced against a climatological lookup table on six months of held-out real weather, and the table won five of them. Both halves shipped.

Is any of this running on real hardware?

No, and it is declared. Telemetry is simulated and every frame carries source="simulator" in the contract, which has no default that could claim otherwise.

What happens when the network fails mid-voyage?

The advisory degrades to the deterministic sentence and says so. The weather panel reports NO SIGNAL and logs that it is advising on default conditions rather than measured weather — it will not claim a sync that did not happen. The captain always gets a number; the provenance is always visible.
